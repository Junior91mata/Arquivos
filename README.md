# Skills do Claude Code

Repositório só de skills, instalado como plugin do Claude Code.

## Instalar (uma vez em cada máquina)

```
/plugin marketplace add Junior91mata/Arquivos
/plugin install skills@arquivos
```

## Atualizar depois de um push

```
/plugin marketplace update arquivos
```

Abrir um chat novo depois de atualizar.

## Acrescentar uma skill

Uma pasta por skill em `Skill/skills/<nome>/`, com o `SKILL.md` (e os arquivos de apoio dele).
Nome da pasta sem espaço e sem acento. Skill copiada de outro repositório leva o `LICENSE` de lá
na própria pasta e a origem abaixo.
